# SlimeVR-ESP32WROOM1N8-Firmware-Flasher
A one-button firmware flasher for my [SlimeVR](https://github.com/SlimeVR) trackers with custom pinouts. Simply go to this repository's [connected website](https://maeday257.github.io/SlimeVR-ESP32WROOM1N8-Firmware-Flasher/), connect the tracker via a data-capable USB cable, and allow the browser to access the tracker. Then select the corresponding firmware. If you are unsure or need technical support, check the documentation included with your trackers or contact me at [maedayVR@gmail.com](mailto:maedayVR@gmail.com).

Disclosure: This flasher was created with help from ChatGPT, but the firmware was configured by me.
